# Папка `kimi/` — мост между Claude и Kimi

Этот каталог — точка обмена задачами между двумя ИИ-агентами:
**Claude** (планирует и ставит задачи) и **Kimi** (выполняет и отчитывается).

## Структура

```
kimi/
├── tasks/       Задачи от Claude (task-001.md, task-002.md, ...)
├── solutions/   Результаты от Kimi (solution-001.md, ...)
└── README.md    Этот файл
```

## Протокол

### 1. Claude создаёт задачу
Файл `kimi/tasks/task-NNN.md` (нумерация сквозная, с нулями: 001, 002, ...):

```markdown
---
status: todo          # todo | in-progress | done | rejected
title: Короткое название задачи
---

## Контекст
Зачем это нужно, ссылки на файлы/папки проекта.

## Задача
Что конкретно сделать. Одна задача = один файл.

## Критерии приёмки
Как проверить, что задача выполнена.
```

### 2. Kimi выполняет
- Читает новые файлы со `status: todo`, меняет статус на `in-progress`.
- Делает работу (правки кода — отдельными коммитами в main).
- Пишет отчёт в `kimi/solutions/solution-NNN.md`: что сделано, список
  изменённых файлов, как проверить, открытые вопросы.
- Меняет статус задачи на `done` (или `rejected` + причина).

### 3. Claude проверяет
Читает `solution-NNN.md`, при необходимости создаёт задачу на доработку.

## Правила
- Одна задача = один файл = один отчёт. Номер задачи = номер решения.
- Не удалять файлы задач и решений — это история.
- Кодовые правки Kimi делает отдельными коммитами с понятными сообщениями.
- Спорные решения Kimi не принимает молча — описывает варианты в отчёте.
